# Dujeen Quest Adventure Overhaul Design

วันที่: 22 กรกฎาคม 2026

## เป้าหมาย

ปรับ Dujeen Quest จากเว็บแบบทดสอบธีมอวกาศให้เป็นเว็บเกมผจญภัยจีนแบบการ์ตูน ผู้เล่นเดินทางกับแพนด้าผ่าน 15 ด่าน เรียนภาษาจีนจากการลงมือทดลอง และรับผลตอบแทนที่ชัดเจนจากทุกภารกิจ โดยรักษาเนื้อหาและระบบมินิเกมเดิมที่ผ่านการทดสอบไว้

## แนวทางที่เลือก

ใช้ Adventure Overhaul บน React, Framer Motion และ DOM เดิม ไม่ย้ายไป Phaser เพราะโครงสร้างภารกิจ 15 ด่าน ระบบบันทึก และชุดทดสอบมีความพร้อมอยู่แล้ว การปรับจะเน้น game loop, presentation, feedback และ progression โดยแยก logic ที่ทดสอบได้ออกจาก component

## แฟนตาซีและเส้นทางผู้เล่น

ผู้เล่นเป็นนักเดินทางที่ร่วมทางกับแพนด้าผู้พิทักษ์ม้วนคัมภีร์ เส้นทางแบ่งเป็น 3 บท บทละ 5 ด่าน:

1. เส้นทางผู้ฝึกหัด: ตลาดจีน ร้านน้ำชา และโรงเรียน
2. เส้นทางนักผจญภัย: หมู่บ้านไผ่ เมืองโบราณ และพระราชวัง
3. เส้นทางปรมาจารย์: ภูเขาหมอก วิหารมังกร และกำแพงเมืองจีน

แต่ละด่านใช้วงจร `Mission Briefing -> Challenge Chain -> Reward Reveal -> Unlock Route` ผู้เล่นเห็นเป้าหมายเชิงเรื่องราวก่อนโจทย์เสมอ และแพนด้าจะให้คำแนะนำตามสถานการณ์แทนข้อความแบบข้อสอบ

## ระดับความยาก

ผู้เล่นเลือกระดับก่อนเริ่มแต่ละด่าน ระบบจดจำระดับล่าสุดใน Local Storage และเปลี่ยนได้อีกครั้งจากหน้าเตรียมภารกิจ

| ระดับ | หัวใจ | เวลา | คำใบ้ | ตัวลวงและคะแนน |
|---|---:|---|---|---|
| นักเดินทางมือใหม่ | 5 | ไม่จับเวลา | อธิบายชัดและไม่เสียเหรียญ | ตัวลวงแยกง่าย ไม่มีโทษคอมโบ |
| นักผจญภัย | 3 | จับเวลาเฉพาะบางภารกิจ | ลดตัวเลือกหรือเผยเบาะแสบางส่วน | ตัวลวงใกล้เคียง มีคอมโบ |
| ปรมาจารย์มังกร | 2 | จำกัดเวลาทุกภารกิจที่รองรับ | ใช้เหรียญและให้เบาะแสสั้น | ตัวลวงใกล้เคียง โบนัสเวลาและคอมโบสูง |

ความยากเปลี่ยนแรงกดดันและความช่วยเหลือ ไม่ตัดเนื้อหาการเรียนรู้ ผู้เล่นทุกระดับเข้าถึงคำอธิบายหลังตอบได้เท่ากัน

## ระบบเล่นและความท้าทาย

- เพิ่ม combo meter เมื่อถูกต่อเนื่อง คอมโบเพิ่มตัวคูณคะแนนและพลังโจมตีต่ออุปสรรคของด่าน
- เพิ่ม mission timer ตามระดับความยาก เมื่อหมดเวลาถือเป็นพลาดหนึ่งครั้ง แต่ยังแสดงคำอธิบายและให้ลองเรียนรู้ต่อ
- คำใบ้มี 3 รูปแบบตามประเภทโจทย์: ตัดตัวเลือก, เผยโครงสร้าง, หรือให้คำใบ้จากแพนด้า
- ตอบผิดเสียหัวใจพร้อม feedback สั้นที่บอกว่าควรสังเกตอะไร ไม่มีหน้าจอ Game Over แบบลงโทษ ผู้เล่นเริ่ม checkpoint ของภารกิจนั้นใหม่
- ดาวคำนวณจากความถูกต้อง หัวใจที่เหลือ เวลา คอมโบ และจำนวนคำใบ้ โดยไม่ลดสถิติสูงสุดเดิมเมื่อ replay
- ด่าน 5, 10 และ 15 เป็น Guardian Encounter ที่ผสมมินิเกมหลายชนิดและแสดงหลอดพลังของอุปสรรค

## งานภาพและ UI

### ภาษาภาพ

- Chinese Fantasy Adventure Cartoon
- สีหลัก: แดงชาด `#A92D2D`, ทอง `#F4C95D`, ครีม `#FFF0CF`, หยก `#2F8C72`, หมึก `#202530`
- วัสดุ: ป้ายไม้ กระดาษม้วน เชือกไหม ขอบทอง ตราประทับ และลายเมฆจีน
- ฉาก: ภูเขาหมึกซ้อนชั้น โคมไฟ ไผ่ หลังคาจีน สะพานหิน และหมอกอุ่น

### หน้าหลัก

หน้าหลักเป็นฉากประตูหมู่บ้านจีน ไม่ใช่ dashboard แพนด้ายืนข้างป้ายภารกิจ ปุ่มหลักเป็นป้ายไม้/ม้วนคัมภีร์ มี CTA เดียวเด่นชัด และทรัพยากรผู้เล่นอยู่ใน HUD ขนาดกะทัดรัด

### แผนที่

แผนที่เป็นเส้นทางแนวตั้งแบบม้วนภาพจีน มี 15 node เชื่อมด้วยเส้นทางคดเคี้ยว แต่ละพื้นที่มี silhouette และสีเฉพาะ ด่านปัจจุบันมีแสงโคมเต้นเบา ด่านล็อกใช้ตราประทับแทนแม่กุญแจทั่วไป

### หน้าภารกิจ

คงพื้นที่กลางไว้สำหรับ interaction ส่วน HUD ด้านบนแสดงหัวใจ ภารกิจ คอมโบ เวลา และ pause เท่านั้น แพนด้าอยู่ริมเวทีพร้อม speech bubble แบบ contextual ไม่วางกล่องข้อมูลขนาดใหญ่รอบจอ

### หน้ารางวัล

ผลลัพธ์เป็นการเปิดม้วนคัมภีร์และประทับตราผ่านด่าน ดาวเผยทีละดวง เหรียญ/XP ลอยเข้าสู่ HUD และเส้นทางถัดไปสว่างขึ้น

## แอนิเมชัน

- Ambient: หมอกเลื่อนช้า โคมแกว่ง ใบไผ่ไหว และแพนด้าหายใจ ใช้เฉพาะ transform/opacity
- Interaction: ป้ายไม้ยกขึ้นเมื่อ hover, ปุ่มยุบเมื่อกด, ชิ้นคำ snap เข้าเบ้าพร้อมเส้นพลังหยก
- Correct: แสงทองพุ่งตามเส้นทาง คอมโบเด้ง และแพนด้าทำท่าดีใจ
- Wrong: การ์ดสั่นสั้น หมึกแดงกระจายเบา และหัวใจแตกหนึ่งดวงโดยไม่ flash ทั้งจอ
- Reward: ดาวปรากฏตามจังหวะ ตราประทับกระแทกม้วนคัมภีร์ และเหรียญเคลื่อนสู่ HUD
- Scene transition: เมฆจีนกวาดหน้าจอ 350–500 มิลลิวินาที
- Reduced motion: ปิด parallax, ambient loop และ particle เหลือ fade/scale สั้นสำหรับ state change

## โครงสร้างโค้ด

- `difficultyConfig`: ค่าหัวใจ เวลา ค่าใบ้ ตัวคูณ และเงื่อนไขดาวต่อระดับ
- `challengeScoring`: pure functions สำหรับคอมโบ คะแนน เวลา และดาว
- `GamePage`: จัด orchestration ของ session แต่ส่งค่าความยากและ event ให้ reducer
- `gameSessionReducer`: ถือ hearts, combo, timer outcome, checkpoint และ feedback state
- `DifficultySelect`: ใช้ร่วมใน Mission Intro และ Pause/Settings
- `AdventureBackdrop`, `GameHUD`, `RewardBurst`: presentation components ที่ไม่ถือ game logic
- CSS variables เก็บ palette, material, shadow และ motion token กลาง

## Data Flow

1. ผู้เล่นเลือกระดับจาก Mission Intro
2. App บันทึก `difficulty` และส่งเข้า `GamePage`
3. reducer สร้าง session จาก level และ difficulty config
4. mission component ส่ง answer event เข้า evaluator
5. reducer อัปเดตหัวใจ คอมโบ คะแนน เวลา และ phase
6. เมื่อจบด่าน `completeLevel` บันทึกรางวัลและ best result โดยไม่ลดของเดิม

## การจัดการข้อผิดพลาด

- Local Storage เก่าที่ไม่มี difficulty ใช้ `adventurer` เป็นค่าเริ่มต้น
- mission ที่ไม่รองรับ timer จะไม่แสดงเวลา แม้อยู่ระดับยาก
- Web Speech หรือ SFX ใช้ไม่ได้ เกมยังเล่นต่อได้และแสดงข้อความสั้น
- เมื่อข้อมูล mission ผิด ระบบกลับหน้าแผนที่พร้อมข้อความ ไม่แสดงจอว่าง
- timer, speech และ pending animation ต้อง cleanup เมื่อ pause, เปลี่ยนข้อ หรือออกจากด่าน

## การทดสอบ

- Unit tests: difficulty config, reducer, combo, timeout, hint cost, score และ star rules
- Component tests: DifficultySelect, HUD states, feedback และ reduced-motion behavior
- Playwright: เลือกความยากทั้งสามระดับ เล่นด่านแรก ตอบผิด/ใช้คำใบ้/หมดเวลา ผ่าน Guardian Encounter และตรวจการจำค่าหลัง reload
- Screenshot review: Home, Map, Mission, Result ที่ 375x812, 768x1024 และ 1440x900
- Regression gates: content validator, unit suite, production build และ existing 15-level flow

## เกณฑ์สำเร็จ

- ภาพแรกอ่านเป็นเกมผจญภัยจีนโดยไม่ต้องอ่านข้อความอธิบาย
- ผู้เล่นเลือกระดับก่อนด่านและระบบจดจำค่าล่าสุด
- การตอบถูก ผิด ใช้คำใบ้ หมดเวลา และผ่านด่านมี feedback ต่างกันชัดเจน
- 15 ด่านและมินิเกมเดิมยังเล่นได้ครบ
- ไม่เผยคำตอบก่อนผู้เล่นตอบตามกฎ content safety เดิม
- desktop/mobile ไม่มี HUD บังพื้นที่เล่น และ reduced motion ใช้งานได้
- unit tests, content validation, build และ Playwright ผ่าน
